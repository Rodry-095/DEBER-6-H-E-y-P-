*Integrantes:

-Alisson Quiguango

*Instrucciones:

Este deber incluye el desarrollo de dos ejercicios aplicando POO en Java:

*Sistema de Subsidio de Gasolina

-Se desarrolló una clase que representa a un solicitante de subsidio, permitiendo validar si cumple con los requisitos establecidos (ingresos, número de vehículos y residencia en Ecuador).
-Se aplicaron conceptos como encapsulamiento, uso de getters y setters, constructores, validaciones y lógica condicional.

*Sistema Bancario

-Se implementó un sistema para gestionar diferentes tipos de cuentas bancarias:

1.- Cuenta de Ahorros
2.- Cuenta Corriente
3.- Cuenta de Inversión

-El sistema permite realizar operaciones como depósitos, retiros y cálculo de intereses mensuales.
-Se aplicaron principios de **herencia, encapsulamiento, abstracción y polimorfismo**, utilizando una clase abstracta y una colección de cuentas para calcular intereses sin distinguir el tipo.

*Instrucciones de Ejecución

1. Abrir el proyecto en un entorno de desarrollo (IntelliJ).
2. Compilar todas las clases del proyecto.
3. Ejecutar la clase `Main` correspondiente a cada ejercicio.
4. Ingresar los datos solicitados en consola (en el caso del subsidio).
5. Visualizar los resultados generados por el sistema.
